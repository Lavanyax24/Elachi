# Elachi

A recipe management Android app with a custom REST API backend.

## Stack
- **Android:** Kotlin, Jetpack Compose
- **Backend:** Node.js, Express
- **Database:** Supabase (PostgreSQL)
- **Auth:** Firebase Authentication
- **Storage:** Supabase Storage
- **Hosting:** Render
